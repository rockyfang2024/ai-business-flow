# 04 · 前端配置界面

> 核心实现：`frontend/src/components/SettingsDialog.tsx`

## 一、组件定位

SettingsDialog 是用户配置 LLM Provider 的唯一入口——在界面直接选择 Provider、填入 API Key、测试连接、保存配置，**无需编辑环境变量或 YAML 文件**。

每条 Provider 包含：

```typescript
interface ProviderEntry {
```

## 四、核心交互逻辑

### 4.1 Provider 搜索与选择

```typescript
// 搜索过滤逻辑：匹配 id / name / description
function filteredGroups() {
  if (!search.trim()) return PROVIDER_GROUPS;  // 无关键词 → 显示全部分组
  const q = search.toLowerCase();
  return PROVIDER_GROUPS
    .map(g => ({
      ...g,
      providers: g.providers.filter(p =>
        p.id.includes(q) ||
        p.name.toLowerCase().includes(q) ||
        p.description.toLowerCase().includes(q)
      ),
    }))
    .filter(g => g.providers.length > 0);
}

// 选择 Provider → 自动填入默认 Base URL + 默认模型
function handleProviderSelect(p: ProviderEntry) {
  setForm({
    ...form,
    provider: p.id,
    model: p.models[0],         // 自动选中第一个模型
    baseUrl: p.defaultBaseUrl,   // 自动填入默认 Base URL
  });
}
```

### 4.2 连接测试

测试使用 **`/api/config/llm/test`** 接口（相对路径，经 Next.js 代理）：

```typescript
async function handleTest() {
  const res = await fetch("/api/config/llm/test", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      provider: form.provider,    // Provider ID
      model: form.model,          // 模型名
      api_key: form.apiKey,       // 用户输入的 API Key
      base_url: form.baseUrl,     // 用户填的 Base URL
    }),
  });
  // 返回 {"status": "ok", "response": "ok"}
  // 或 {"detail": "LLM call failed [openrouter]: ..."}
}
```

**关键点**：这里用的是相对路径 `/api/config/llm/test`，而不是 `http://localhost:8000/api/...`。这是因为浏览器请求从 `localhost:3000` 发出，CORS 会拦截直接打到 `localhost:8000` 的请求。Next.js 的代理配置（`next.config.js`）将 `/api` 路径转发到后端。

### 4.3 配置保存

```typescript
function handleSave() {
  if (!form.apiKey.trim()) {
    alert("请输入 API Key");
    return;
  }
  onSave(form);   // 回调给父组件 → 写入 YAML 文件
  onClose();
}
```

保存时，父组件将配置写入 `llm_config.yaml`，后续 API 调用通过 `config.py` 加载。

## 五、CORS 陷阱与修复记录

### 曾经踩过的坑：硬编码 localhost:8000

```typescript
// ❌ 错误写法（导致 CORS 错误）
const res = await fetch("http://localhost:8000/api/config/llm/test", ...);

// ✅ 正确写法（相对路径，走 Next.js 代理）
const res = await fetch("/api/config/llm/test", ...);
```

**原因**：浏览器访问 `http://localhost:3000` 时，AJAX 请求的 origin 是 `localhost:3000`，直接请求 `localhost:8000` 会触发浏览器的 CORS 限制。正确做法是走 Next.js 代理——前端发到 `/api/*`，Next.js 转发到 `http://localhost:8000`。

Next.js 代理配置（`next.config.js`）：

```javascript
// next.config.js
{
  async rewrites() {
    return [{ source: "/api/:path*", destination: "http://localhost:8000/api/:path*" }];
  },
}
```

## 六、Next.js API 代理配置

`frontend/next.config.js` 同时配置了开发环境允许的远程访问 origin：

```javascript
{
  async headers() {
    return [{
      source: "/api/:path*",
      headers: [
        { key: "Access-Control-Allow-Origin", value: "*" },
      ],
    }],
  },
}
```

## 七、SettingsDialog 的 Props 接口

```typescript
interface Props {
  open: boolean;                          // 是否打开
  onClose: () => void;                     // 关闭回调
  config: LLMConfig;                      // 当前配置（从 YAML 加载）
  onSave: (config: LLMConfig) => void;    // 保存回调
}

interface LLMConfig {
  provider: string;   // "openrouter"
  model: string;      // "anthropic/claude-sonnet-4.6"
  apiKey: string;      // "sk-or-v2-..."
  baseUrl: string;     // "https://openrouter.ai/api/v1"
}
```

## 八、与后端 Provider 注册表的关系

```
后端 backend/app/llm_config.py
        │
        │  32 个 ProviderProfile 注册
        │  包含：base_url, env_vars, transport, aliases...
        │
        ▼
前端 SettingsDialog.tsx
        │
        │  前端只存展示用的 ProviderEntry
        │  （id, name, description, defaultBaseUrl, models, envHint）
        │
        ▼
用户选择 Provider
        │
        ▼
POST /api/config/llm/test  ← 后端根据 provider id 查找对应 ProviderProfile
        │
        ▼
create_llm_client(provider, model, api_key, base_url)
        │
        ▼
匹配 transport → 路由到对应 Client（OpenAI/Anthropic/Bedrock/Codex）
```

**前端与后端的唯一契约**：`provider id`（如 `"openrouter"`）和 `model`（如 `"anthropic/claude-sonnet-4.6"`）。前端不暴露认证细节（API Key 只存在于用户输入和 YAML 文件）。
