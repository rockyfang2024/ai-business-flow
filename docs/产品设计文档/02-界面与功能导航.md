# 02 · 界面与功能导航

> 配图建议：本文档配合线上系统截图阅读效果最佳。

## 一、整体页面结构

打开系统后，分为左右两栏：

```
┌─────────────────┬────────────────────────────────────────────┐
│                 │                                            │
│  业务流程列表    │           业务流程详情                      │
│  （左侧栏）      │           （右侧主区域）                     │
│                 │                                            │
│  [+ 新建]       │  ┌──────────┬──────────┬──────────┐       │
│                 │  │ 文档     │ 知识结构  │ 对话      │       │
│  ● 请假流程     │  └──────────┴──────────┴──────────┘       │
│  ● 退款流程  ✓  │                                            │
│  ○ 供应商准入   │  （三 Tab 内容区）                          │
│                 │                                            │
│                 │                           [⚙️ 设置]        │
└─────────────────┴────────────────────────────────────────────┘
```

**左侧栏** = 流程列表，**右侧** = 选中流程的详情（三个 Tab）

---

## 二、左侧栏：业务流程列表

### 2.1 新建流程 [+]

**位置**：左侧栏顶部

**操作**：点击 `[+]` → 弹出"新建业务流程"对话框 → 输入流程名称（如"供应商准入审批"）→ 点击"创建"

**效果**：新流程出现在列表中，自动进入详情页面

---

### 2.2 流程列表项

每个列表项显示：
- **流程名称**（如"请假审批"）
- **状态标签**：有"✓ 已梳理"标签 = 该流程已完成知识抽取
- **更新日期**

**操作**：点击任一流程 → 右侧区域展示该流程详情

---

### 2.3 删除流程

**位置**：在流程列表项上右键 或 在流程详情页操作

**注意**：删除后不可恢复，所有文档和知识结构都会清除。

---

## 三、右上角：⚙️ LLM 设置

**位置**：右侧主区域右上角，有 ⚙️ 图标

**操作**：点击 → 弹出 LLM 设置弹窗

### 设置弹窗内容

```
┌──────────────────────────────────┐
│  ⚙️ LLM 设置               [✕]  │
├──────────────────────────────────┤
│                                  │
│  提供商                          │
│  ┌──────────────────────────┐   │
│  │ OpenRouter            ▼  │   │  ← 点击选择/搜索 AI 服务商
│  └──────────────────────────┘   │
│  说明：200+ 模型统一入口，支持...  │
│                                  │
│  Base URL                        │
│  ┌──────────────────────────┐   │
│  │ https://openrouter...    │   │  ← 通常不需要改
│  └──────────────────────────┘   │
│                                  │
│  API Key                         │
│  ┌──────────────────────────┐   │
│  │ ••••••••••••             │   │  ← 粘贴你的 API Key
│  └──────────────────────────┘   │
│  （环境变量: OPENROUTER_API_KEY）│  │
│                                  │
│  模型                            │
│  ┌──────────────────────────┐   │
│  │ anthropic/claude-sonnet▼ │   │  ← 选择使用的 AI 模型
│  └──────────────────────────┘   │
│                                  │
│  ✅ 连接成功：ok                  │  ← 测试结果提示
│                                  │
├──────────────────────────────────┤
│  [🔌 测试连接]    [取消] [保存]  │
└──────────────────────────────────┘
```

**填写步骤**：
1. **选择提供商**：在下拉框搜索（如输入 "deepseek"）
2. **填入 API Key**：从 AI 服务商网站复制 key，粘贴进去
3. **选择模型**：系统会根据你选的提供商自动显示可选模型
4. **测试连接**：点击"测试连接"验证 key 是否有效
5. **保存**：点击"保存"，设置写入配置文件

**⚠️ 重要**：API Key 是你的账号凭证，**不要泄露给他人**。保存在本地配置文件里，不上传到网络。

## 四、三 Tab：文档 / 知识结构 / 对话

### 4.1 文档 Tab（第一个 Tab）

**位置**：切换 Tab 的第一个标签

**作用**：上传业务文档、触发 AI 知识抽取

**操作区域**：

```
┌──────────────────────────────────────────────────┐
│  📎 选择 Markdown 文件    或输入本地文件路径：     │
│                                          [上传]  │
├──────────────────────────────────────────────────┤
│  已上传文档（2）                                  │
│  ├── usdt-deposit.md  12.3 KB · 2025/5/25 10:30  │
│  └── refund-policy.md  5.2 KB · 2025/5/25 10:31  │
├──────────────────────────────────────────────────┤
│  [🧠 开始 AI 知识抽取]                            │
│  ✅ 抽取完成，请切换到「知识结构」标签查看          │
└──────────────────────────────────────────────────┘
```

**操作说明**：

| 操作 | 说明 |
|------|------|
| 选择 Markdown 文件 | 点击"📎 选择文件"→ 选本地 `.md` 文件 → 自动上传 |
| 输入文件路径 | 直接填服务器上的文件绝对路径（如 `/home/user/docs/xx.md`），点击"上传" |
| 开始 AI 抽取 | 上传文档后，点击"🧠 开始 AI 知识抽取"→ AI 自动解析文档 |

**状态提示**：
- `⏳ AI 正在抽取...` = 抽取进行中
- `✅ 抽取完成` = 已生成结构化文档，可切换到"知识结构" Tab 查看
- `❌ 错误` = 抽取失败，可查看错误信息

---

### 4.2 知识结构 Tab（第二个 Tab）

**位置**：切换 Tab 的第二个标签

**前置条件**：必须先完成"文档抽取"或"对话式梳理"，否则显示"暂无数据"

**界面**：

```
┌──────────────────────────────────────────────────┐
│  [主流程] [决策树] [异常矩阵] [SLA]  ← 切换查看  │
├──────────────────────────────────────────────────┤
│                                                  │
│  process:                                        │
│    name: USDT 充值流程                          │
│    version: "1.0"                               │
│    last_updated: "2025-05-25"                    │
│    steps:                                        │
│      - step: 1                                   │
│        name: 用户提交充值申请                    │
│        owner: 用户                               │
│        input: 充值金额 + 地址                    │
│        output: 充值订单                          │
│        sla: 5分钟内完成                          │
│        ...                                       │
│                                                  │
└──────────────────────────────────────────────────┘
```

**四个视图**：

| 视图 | 内容 |
|------|------|
| **主流程** | 流程步骤清单，每步有负责方、输入、输出、SLA |
| **决策树** | 分支判断条件，告诉你在什么情况下走哪条路 |
| **异常矩阵** | 所有异常情况 + 对应处理方式 |
| **SLA** | 每步的时效要求（5 分钟内、24 小时内等）|

---

### 4.3 对话 Tab（第三个 Tab）

**位置**：切换 Tab 的第三个标签

**作用**：没有文档时，通过对话让 AI 引导你一步步梳理业务流程

**界面**：

```
┌──────────────────────────────────────────────────┐
│  （对话模式切换区）                               │
│  [问答模式] [对话模式]  ← 当前：对话模式          │
├──────────────────────────────────────────────────┤
│                                                  │
│  🤖 好的，请问你希望梳理什么业务流程？             │
│                                                  │
│  👤 我想做一个供应商准入的流程                    │
│                                                  │
│  🤖 好的，供应商准入流程。请回答以下问题：         │
│     1. 供应商准入由谁发起？（采购 / 销售 / ...） │
│                                                  │
│  👤 由采购发起                                    │
│                                                  │
│  �وي 明白了。请问采购提交准入申请后，谁来审批？   │
│                                                  │
├──────────────────────────────────────────────────┤
│  [输入消息...                      ] [发送]       │
└──────────────────────────────────────────────────┘
```

**两种模式**：

| 模式 | 说明 |
|------|------|
| **问答模式** | 基于已有知识结构回答业务问题（如"这个流程的第一步是什么？"）|
| **对话模式** | 从零构建业务流程，AI 逐步提问引导你 |

**切换规则**：当知识结构为空时自动进入"对话模式"；已有知识结构时自动进入"问答模式"。

**操作说明**：

| 操作 | 说明 |
|------|------|
| 输入消息 | 在底部输入框输入文字 |
| 发送 | 按 Enter 或点击"发送" |
| 中断对话 | 关闭页面即可，下次进入会继续上次的对话 |

**完成信号**：当 AI 认为收集足够信息后，会在回复末尾显示"我已经收集到足够信息"，并自动生成结构化文档 → "知识结构" Tab 出现数据。

## 五、操作流程速查

| 你想做什么 | 去哪里 | 操作 |
|-----------|--------|------|
| 创建新流程 | 左侧栏 | 点击 [+ 新建] |
| 上传业务文档 | 文档 Tab | 点击"选择文件"或填路径上传 |
| 提取知识结构 | 文档 Tab | 上传后点击"🧠 AI 抽取" |
| 查看生成的 YAML | 知识结构 Tab | 点击切换 4 个视图 |
| 从零构建流程 | 对话 Tab | 直接开始对话，AI 引导你 |
| 回答流程问题 | 对话 Tab | 在知识结构已生成后，进入问答模式 |
| 切换 AI 模型 | 右上角 ⚙️ | 修改 Provider、API Key、模型 |
| 删除流程 | 左侧栏 | 右键或流程详情页操作 |
