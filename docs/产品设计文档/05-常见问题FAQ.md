## 一、文档上传问题

### Q1：上传文档时提示"文件类型不支持"，怎么办？

**原因**：上传的文件扩展名不在支持列表中。

**解决方法**：
1. 确认文件是以下格式之一：`.docx`、`.pdf`、`.txt`、`.md`
2. 如果是 WPS 或 Pages 格式的文档，另存为上述标准格式后再上传
3. 如果是扫描件 PDF（图片合成的 PDF），建议先用 OCR 工具转成文字

**操作示例（Word 转 PDF）**：
> WPS → 文件 → 另存为 → 选择 .pdf 格式 → 保存

---

### Q2：上传文档成功，但 AI 说"没有读取到内容"，怎么办？

**原因**：文档可能是加密的、受保护的，或者文字是图片嵌入的。

**解决方法**：
1. 确认文档没有被密码保护（解除方法：WPS/Word → 审阅 → 限制编辑 → 停止保护）
2. 如果是扫描件，请先使用 OCR 工具提取文字
3. 尝试将文档另存为 `.txt` 纯文本格式重新上传

---

### Q3：可以同时上传多个文档吗？

**可以**。支持一次性选择多个文件一起上传，系统会将多个文档的内容**合并分析**。

> **适用场景**：例如"退货流程"文档在 3 个文件里（主流程、异常处理、客服话术），可以一起上传让 AI 综合理解。

---

### Q4：上传文档大小有限制吗？

**建议单个文件不超过 10MB**。

如果文档过大，可以：
1. 将长文档拆分成多个小文件分批上传
2. 删除文档中不影响业务含义的图片和格式信息，减小文件体积

## 二、AI 梳理问题

### Q5：AI 分析结果和实际流程有出入，怎么办？

**这是正常现象**，AI 初次分析不一定完美，需要人工确认和补充。

**正确流程**：
1. 查看 AI 生成的结果（右侧"知识结构"标签页）
2. 回到"对话"标签页，告诉 AI 需要修改的地方
3. 例如："第三步的责任人应该是店长，不是客服"
4. AI 修正后会告诉你"已更新"，再次查看知识结构确认

**常见调整指令示例**：
- "把第 X 步的负责人改成 XXX"
- "补充一个判断条件：如果是 VIP 客户，则走快速通道"
- "删除第 X 步，这个步骤在实际操作中不存在"
- "在步骤 2 和步骤 3 之间增加一个新步骤"

---

### Q6：AI 回复说"无法理解文档内容"，怎么办？

**原因**：文档内容可能不包含明确的流程描述（如仅是财务报表、代码日志等）。

**解决方法**：
1. 确认文档内容是描述"某个人在什么条件下做了什么操作"的流程性文档
2. 在对话中主动给出补充说明："这是一个退货处理流程，包含以下步骤..."
3. 如果文档确实无法提取流程，系统支持你直接描述流程给 AI，让它帮你整理

---

### Q7：对话中途 AI 突然"失忆"了，忘记了之前说的内容？

**原因**：当前对话窗口的上下文记忆有限，历史上传文档内容在超过一定对话轮数后可能不再被引用。

**解决方法**：
1. 在较长的对话中，适当重新上传文档并说明："继续基于之前上传的文档，补充以下内容..."
2. 或者在导出后重新开启新对话进行补充

---

### Q8：AI 分析时间很长，怎么回事？

**正常等待时间**：
- 3 万字以内的文档初次分析：10–30 秒
- 如果超过 2 分钟仍未返回，可以尝试：
  1. 刷新页面，重新上传文档
  2. 检查网络连接是否稳定
  3. 稍后再试（服务器繁忙时段可能较慢）

## 三、YAML 导出问题

### Q9：导出的 YAML 文件打开是乱码，怎么办？

**原因**：使用了系统不支持的文本编辑器打开 YAML 文件。

**解决方法**：
1. 使用以下工具打开 YAML 文件：
   - Windows：记事本（开始 → 附件 → 记事本）、VS Code、Notepad++
   - Mac：TextEdit、VS Code
   - 浏览器：直接拖拽到 Chrome 窗口
2. **不要使用** Word 或 WPS 直接打开（它们会尝试格式化内容，导致乱码）

---

### Q10：导出的 4 个文件有什么区别？我应该用哪个？

**四个文件各有分工**：

| 场景 | 推荐文件 |
|------|---------|
| 快速了解这个流程是什么 | `basic_info.yaml` |
| 制作 SOP 培训文档、招聘要求 | `process_steps.yaml` |
| 分析流程风险、排查纠纷 | `decision_points.yaml` |
| 制定考核指标、监控时效 | `key_metrics.yaml` |

> 如果你不确定从哪个文件开始，**优先看 `process_steps.yaml`**，它包含了最完整的流程步骤描述。

---

### Q11：导出的 YAML 可以再导入回系统修改吗？

**暂不支持**。当前版本导出为单向操作。如果需要修改，建议：
1. 在系统内重新打开对应流程的对话
2. 告诉 AI 需要修改的内容
3. 重新导出

---

### Q12：导出的 YAML 可以在其他系统使用吗？

**可以**。YAML 是通用格式，可以被以下系统导入：
- 流程引擎（Flowable、Camunda 等）
- 低代码平台（织信、氚云等）
- 培训管理系统（SAP SuccessFactors 等）
- 自定义开发系统

## 四、系统设置问题

### Q13：怎么配置我公司的 LLM API？

**操作步骤**：
1. 点击左下角 **"设置"（齿轮图标）**
2. 在设置面板中找到 **"LLM 提供商"** 配置区域
3. 选择你使用的 LLM 服务商（如 OpenAI、Claude、本地模型等）
4. 填入 API Key 和相关配置
5. 保存后，系统会自动连接

> 具体支持哪些 LLM 服务商，请参考系统设计文档中的《LLM 配置系统》章节。

---

### Q14：配置了 API 但提示"连接失败"，怎么办？

**排查步骤**：
1. 确认 API Key 没有多余的空格或换行符
2. 确认 API Key 具有调用权限（部分平台需要开通对应服务）
3. 确认网络可以访问 LLM 服务商的接口（部分企业内网需要配置代理）
4. 查看错误提示信息，截图联系技术支持

---

### Q15：可以同时配置多个 LLM 服务商吗？

**可以**。系统支持配置多个 LLM 提供商，并设置优先级。
- 当前一个提供商不可用时，系统会自动切换到下一个
- 你也可以在对话界面中手动指定使用哪个模型

## 五、其他问题

### Q16：流程数据保存在哪里？会不会丢失？

**数据存储位置**：
- 对话记录、流程配置保存在服务器的 `dialogue_history.json` 文件中
- 上传的原始文档保存在服务器的 `uploads/` 目录

**数据安全建议**：
- 重要流程建议定期导出 YAML 文件备份
- 如果部署在公有云，建议开启服务器的自动备份功能
- 私有部署环境下，数据完全保存在你的服务器，不会外传

---

### Q17：可以给不同的人分配不同的流程权限吗？

**当前版本**（v1.0）**不支持细粒度权限控制**，所有用户可以查看和编辑所有流程。

**临时解决方案**：
- 不同团队使用不同的系统实例（各自部署一套）
- 或者在部署层面通过账号体系做隔离（需要定制开发）

---

### Q18：手机可以访问这个系统吗？

**可以**。系统前端是响应式设计，支持在手机浏览器中访问基本功能。

> 但建议在电脑端使用，以获得完整的操作体验（尤其是上传文档和查看 YAML 导出结果）。

---

### Q19：系统支持私有化部署吗？

**支持**。系统提供 Docker 镜像，可以部署在：
- 企业内网服务器
- 私有云（阿里云、腾讯云、华为云等）
- 本地开发机

详细部署步骤请参考系统设计文档《Docker 部署》章节。
